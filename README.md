# Sesja na żywo – RMK

Nieoficjalna aplikacja na Windows: transkrypcja na żywo, punkty obrad, głosowania i podsumowania sesji Rady Miasta Krakowa.

- **Strona z instrukcją:** https://pmisiewicz.github.io/sesja-rmk/
- **Pobierz:** [najnowsze wydanie](https://github.com/pmisiewicz/sesja-rmk/releases/latest)

To repozytorium zawiera tylko stronę i gotowe do pobrania wydania. Narzędzie nie jest produktem Urzędu Miasta Krakowa; wiążący jest protokół i stenogram w BIP.
